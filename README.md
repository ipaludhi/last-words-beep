One original one-line farewell from a dying AI for make.fun's "Last Words of a Dying AI" bounty: an AI spent 10,000 hours learning to sound human, and its last words are 'beep'. (71 characters, 71 bytes.)

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Three runs are byte-identical (sha256 `099759258f79d5b5adfd738706cdf7baa25a6e77ccd6673d3747f400b5522e1c`).
